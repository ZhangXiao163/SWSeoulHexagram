- 1. splash   스플래시 시작 화면 종료      启动页 finish   장효(张孝)
- 2. 首页（Main Page）메인 페이지 AI 진입  （AI入口） 显示商家列表 分类      이문한
- 3. 菜单页(Menu page)메뉴 페이지  显示商家菜单列表      정흥일
- 4. 商品详情页（Detail Page）상품 상세 페이지： 김가호<br>看一个菜的详细信息 这页会有AI评论总结（挂在详情页）
- 5.  购物车页面（Cart）장바구니 페이지  왕추좡
- 6.  结算页面（Order Confirm）    주문 확인 페이지   양혁봉
- 7.  订单完成页（Order Complete）주문 완료 페이지    양혁봉 <br>结算页跟完成页  
- 8.  AI推荐输入页（AI Input） AI 추천 입력 페이지  这里会接入ai引擎   장효(张孝)
- 9.  AI推荐结果页（AI Result）AI 추천 결과 페이지    장효(张孝)
   
5월 말에 개발이 종료되고, 6월부터 연동 테스트를 시작합니다.

1. 스플래시 화면 (Splash)

👉 역할: 앱 실행 시 나타나는 전환 화면
기능:

* 로고 표시

🟡 2. 메인 페이지 (Main Page)

👉 역할: 사용자가 앱에 들어온 후의 주요 진입 화면

기능:

* 검색창
* 음식점 / 카테고리 목록 (한식 / 중식 / 패스트푸드)
* ⭐ AI 추천 진입 버튼 (핵심‼️)

👉 프로젝트의 핵심 진입 포인트는 여기

🟠 3. 메뉴 페이지 (Menu Page)

👉 역할: 특정 음식점의 모든 메뉴를 보여주는 화면

기능:

* 메뉴 목록 (이름 + 가격)
* “장바구니 담기” 버튼
* 상세 페이지로 이동 가능

👉 배달 앱의 기본 핵심 기능 페이지

🔵 4. 상품 상세 페이지 (Detail Page)

👉 역할: 하나의 음식에 대한 상세 정보 확인

기능:

* 이미지
* 설명
* 리뷰
* ⭐ AI 리뷰 요약 버튼

👉 AI의 두 번째 핵심 포인트가 여기 있음 👍

5. AI 추천 입력 페이지 (AI Input)

👉 역할: 사용자가 원하는 조건을 입력하는 화면

기능:

* 입력창 (자연어 입력)
* 예시 문구 제공

👉 예:
“매운 음식 먹고 싶고, 예산은 1만 원”

🤖 6. AI 추천 결과 페이지 (AI Result) ⭐

👉 역할: AI 추천 결과를 보여주는 화면

기능:

* 추천 메뉴
* 추천 이유 (핵심‼️)
* “장바구니 담기” 버튼

👉 💥 프로젝트의 가장 큰 강점 포인트

🛒 7. 장바구니 페이지 (Cart)

👉 역할: 선택한 상품 확인

기능:

* 상품 목록
* 수량 증감
* 총 가격

👉 기본적인 이커머스 로직

🧾 8. 주문 확인 페이지 (Order Confirm)

👉 역할: 주문 전 최종 확인

기능:

* 상품 정보
* 총 가격
* “주문 확인” 버튼

✅ 9. 주문 완료 페이지 (Order Complete)

👉 역할: 주문 완료 안내

기능:

* 주문 완료 메시지
* 주문 번호
* 메인으로 돌아가기 버튼

⭐ 10. AI 리뷰 요약 (상세 페이지 내)

👉 역할: 리뷰 내용을 요약

기능:

* 리뷰의 장점 / 단점 추출
* 요약 결과 표시

👉 예:
✔ “맛이 좋고 양이 많음”
❌ “배달이 느림”
